WipShare - install
==================

Double-click  "Install WipShare.bat"

It installs WipShare for your user account (no admin needed) and:
  - copies WipShare.exe to %LOCALAPPDATA%\Programs\WipShare
  - adds a Start-menu shortcut
  - turns on launch-at-startup (you can switch this off in WipShare > Settings)
  - registers an entry under Settings > Apps so you can uninstall cleanly

To uninstall:
  Settings > Apps > Installed apps > WipShare > Uninstall
  (or run Uninstall-WipShare.ps1)

WipShare.exe is self-contained - no .NET install is required. Your settings and
invite code are kept on uninstall.
